# LinkedIn Post - Java 17 & Spring Boot 3.3.5 Migration

---

🚀 Just completed a major migration: Java 8 → Java 17 and Spring Boot 1.4.3 → 3.3.5

After migrating my Spring Boot example repository, I documented the entire journey - from the challenges faced to how AI tools like Claude Code and Cursor accelerated the process.

**Key highlights:**
✅ Migrated from Java 8 (2014) to Java 17
✅ Upgraded Spring Boot across 2 major versions (1.4.3 → 3.3.5)
✅ Migrated all tests from JUnit 4 to JUnit 5
✅ Replaced Springfox with SpringDoc OpenAPI
✅ Updated CI/CD pipelines and added code coverage

**The challenges:**
- Breaking changes in Spring Security configuration
- Complete Swagger migration (Springfox → SpringDoc)
- JUnit 4 to JUnit 5 migration across multiple test files
- Dependency compatibility issues

**How AI tools helped:**
AI assistants like Claude Code and Cursor proved invaluable by:
- Automatically identifying compatibility issues
- Assisting with refactoring (especially test migrations)
- Suggesting dependency updates
- Generating new test code following best practices

The migration wasn't just about updating versions - it was an opportunity to improve code quality, add better test coverage, and modernize the entire stack.
